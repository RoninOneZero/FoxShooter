# Summary
Player character is a space operative armed with a knife and pistol.
Game area is a single screen.
Enemies can spawn offscreen or a random spot on screen for added difficulty.
Player has to survive 2 minutes to progress the stage.
Cash is earned per killed enemy. 
Different enemy types reward different amount of cash.
Cash can be spent at the shop on consumables or permanent upgrades.

# Gameplay 
Primary weapon is a pistol.
Single shot, holds 10 rounds by default.
basic damage, takes 2-3 rounds to kill a basic enemy.
Can randomly critically hit, killing an enemy instantly.
Pistol's base crit chance is 10%.
Weapons have a penetration chance. Pistol starts at 0.5

0 = no chance to penetrate
0.5 = penetrates half the time
1+ = penetrates at least once

Whole number values indicate a guarantee to penetrate that many enemies. Remaining decimal value indicates chance to penetrate 1 additional time
